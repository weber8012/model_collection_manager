# 模型與玩具收藏管理系統 (Model Collection Manager)

## 專案簡介

模型與玩具收藏管理系統是一個使用 Python、PySide6 與 SQLite 開發的桌面應用程式，旨在協助收藏者管理塑膠組裝模型、完成品玩具、預購商品及收藏紀錄。

透過整合商品資料、收藏紀錄、存放位置與預購資訊，提供集中化的收藏管理方式，並降低人工管理大量收藏品的困難。

## 開發動機

隨著模型與玩具收藏數量增加，商品資料、購入紀錄、預購資訊及實際存放位置容易分散，難以統一管理。

因此開發此系統，將收藏相關資料整合至 SQLite 資料庫，並透過桌面 GUI 提供直覺的操作介面。

## 系統功能

### 商品管理
- 新增、查詢、修改及刪除商品資料。
- 管理商品名稱、品牌、作品系列、製造商、比例、型號及發售日期。
- 管理商品定價、圖片路徑及備註。

### 收藏管理
- 管理實際持有的商品。
- 記錄購入日期、購入價格及存放位置。
- 查詢及維護收藏紀錄。

### 預購管理
- 管理尚未到貨的預購商品。
- 記錄預購店家、預購價格及相關資訊。
- 維護預購紀錄。

### 存放位置管理
- 建立及管理收藏品存放位置。
- 將收藏紀錄與存放位置關聯。

### 店家管理
- 建立及管理預購店家資料。
- 將預購紀錄與店家關聯。

### 資料庫備份與還原
- 建立 SQLite 資料庫備份。
- 驗證備份資料庫完整性。
- 還原前自動建立安全備份。
- 檢查資料庫完整性與外鍵約束。
- 拒絕無效或損壞的資料庫檔案。

└── run_app.py       # GUI 執行程式

## 資料庫設計

系統使用 SQLite 作為資料持久化工具，透過關聯式資料庫管理商品、收藏、預購、店家及存放位置等資料。

資料表透過 Primary Key 與 Foreign Key 建立關聯，並使用 Repository Pattern 將資料庫操作與 UI 分離。
